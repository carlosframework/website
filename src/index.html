Why CARLOS is different?

Bring the stack into your app. Spend less time wiring services together.

  • Single process

    One process contains the interface, server, database and jobs.

  • Independent instances

    Each customer gets an independent app instance.

  • Deploy anywhere

    Deploy instances by region, in the cloud or on your own infrastructure.

What does better mean?

Build better apps

Speed

If you care about moving fast and making performant apps, speed underpins the CARLOS architecture.

  • Faster builds
  • Faster iteration
  • Faster deployments
  • Faster performance

An agentic embrace

CARLOS is built by agents following the 11 factors.

  • Agent-driveable, human-operable
  • CARLOS apps can be used by humans and agents alike
  • Web apps and CLIs in the same binary
  • Each tenant gets their own API endpoints

Ready for native

The most common database for native apps? SQLite. CARLOS apps make it delightfully easy to build native apps on top.

  • Share database schema with native apps
  • Data is already isolated per tenant
  • Share application logic between web and native apps, with fully native UIs

Accessibility

Turn back the tide of non-inclusive software.

  • Demand WCAG 2.2 AA compliance from day one
  • Ship apps that are accessibility audit-ready and stay that way
  • Acknowledge the irony that human-accessible is also agent-accessible

Run them efficiently

Value for money

Ever feel like compute got cheaper but software got more expensive?

  • Eliminate waste from technology spend
  • Cut TCO by 70% or more without compromising

Carbon conscious

CARLOS is all about doing more with less.

  • Use 30x less compute for equivalent or increased capabilities

Data resilience and control

Each tenant database is continuously streamed to object storage.

  • Easily provide full access to customer data
  • Back up with 1–2s latency rather than nightly
  • Backup becomes part of operations

Robust deployments

CARLOS apps feel like SaaS apps, but split compute and data by tenant, unlocking a host of benefits.

  • Get features live within seconds
  • Deploy with zero downtime
  • Get the flexibility of single-tenant with the UX of multi-tenant

Stay in control

Sovereignty and vendor freedom

CARLOS apps compile to single binaries, which can be placed anywhere in the world, on any hardware.

  • Cloud, on-prem, hybrid: all first-class
  • Deploy apps or instances of apps to any region
  • Use one provider or many

Security

Ace your next ISO27001 or SOC2 audit.

  • Separate every customer’s data
  • Build E2EE where required
  • Trivially deploy any app on-prem where required

Customisability

When every tenant has their own instance, the opportunities for customisation are infinite.

  • Build custom apps for customers on a shared core
  • Let customers run their own version

Flexibility

Alongside control, CARLOS gives you the ability to mix and match deployments.

  • Big customer? Give them dedicated compute
  • Not everyone has to upgrade at once
  • Release pipelines let you roll features out gradually
