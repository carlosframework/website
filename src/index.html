01

A more sovereign architecture

By default, CARLOS apps are broken down into full-stack deployable instances that run as single processes with embedded databases that can run independently or as part of a SaaS like app deployment. This introduces huge flexibility and portability gains without compromising user experiences.

Before CARLOSWith CARLOSBenefits
Monolithic multi-tenant appsSingle-process per tenantMuch more flexibility
Centralised multi-tenant databasesDatabase per-tenantMore secure, more control
Nightly backupsContinuous streamingRobust data-storage
Single-deployment per appFlexible deployment per tenantEasily deploy multi-platform, multi-region, or self-hosted
Everyone updates at onceTenants can choose whether to upgradeCustomers have more control
