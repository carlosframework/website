CARLOS Platform

Deploy apps and static sites on hosted Carloku, or run CARLOS Platform in your own infrastructure.

Start with CarlokuSelf-host CARLOS Platform

CARLOS Platform is a love-letter to Heroku. Heroku was the best platform as a service and was never beaten for developer experience. CARLOS Platform aims to allow folks the ultimate dream: to get started quickly and easily with a hosted platform like Carloku, but to be able to bring the entire platform into their own infrastructure as needs must.

App requests go to regional edges. Deployment metadata and tenant backups live in separate buckets.

Ship

Deploy apps and static sites with signed releases and named channels. Create branch previews, promote through bake windows and approvals, and roll back to an earlier release. Use zero-downtime swaps on configured hosts.

Run

Place tenant instances by region. Hibernate idle apps and wake them on request. Use one-way read replicas, customer-owned fleets and optional sidecars. Run scheduled jobs and one-off commands.

App services

Custom domains, automatic TLS certificates, secrets, environment configuration and feature flags. Approved object storage with malware scanning, plus email with verified domains and delivery events.

Operate

Use scoped credentials for automation. Follow logs, grouped errors, availability and optional cookieless analytics. Roll platform updates out in stages.

Data

Litestream streams tenant SQLite changes to regional S3 storage. Restore databases or inspect earlier points in time.

Self-host CARLOS Platform

Run compute on your own infrastructure. Current integrations use AWS S3, SES email and Route 53 steering.
