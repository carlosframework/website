How it works

A CARLOS deployment is a console, a bucket and some boxes. This page shows what each one holds, then walks through what happens when you deploy, when a request arrives, and when a box fails.

The parts

Most instances sleep when nobody uses them, so they cost almost nothing. This is what happens when someone visits one.
