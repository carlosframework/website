Your first app

About 10 minutes on a running deploymentYou will need: a terminal and Go 1.26

You will ship a small Go app with its own database, open it, watch it go to sleep, and wake it with a request.

Before you start

You need a CARLOS deployment you can sign in to. Pick one:

  • Install your ownFollow Install a deployment, about an hour, then come back here.
  • Use one that is already runningYour team's, or a hosted deployment such as carloku.com. Sign up there, then carry on.

Install your own: links to the install tutorial, which ends by sending you back to step 1.

Use a running deployment: what you need from it (its console address and an account), and nothing more.

Steps

  1. Install the CLI

    brew install carlosframework/tap/carlos
carlos version

  2. Sign in to your deployment

    carlos auth login --console https://console.example.com

    It prints a short code to approve in your browser.

  3. Get the example app

    A Go program that serves a page and counts visits in SQLite. It is in the platform repository under examples/hello.

    cd examples/hello
GOOS=linux GOARCH=arm64 go build -o hello .

  4. Ship it

    carlos deploy --app hello ./hello

    It creates the app and its first instance, ships the binary and waits for it to answer.

  5. Open it, then let it sleep

    carlos instances list --app hello

    Open the HOST it shows in your browser. After a few minutes without visits, the list shows the instance asleep.

  6. Wake it

    Reload the page. The first request wakes the instance, and the count carries on where it left off.

What you just saw

An app that costs almost nothing while nobody uses it, and keeps its data while it sleeps. How a request wakes an instance shows what happened on step 6.
